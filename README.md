# SceneButton Maker

ココフォリア向けのランダム表・ボタン画像を作成するWebアプリです。表の編集、試し振り、デザイン、パネル配置、PNG・TXT・JSON・ZIP出力に対応しています。

このリポジトリには、ローカルで検証した公開用ビルドとGitHub Pagesの公開設定を配置しています。`site/`が公開対象です。

## 保存と使い方

編集内容は使っているブラウザのIndexedDBに保存します。ログインやサーバー保存は使用しません。別の端末・ブラウザ・URLへ移る場合は、編集用JSONを書き出し、移行先の「プロジェクト管理」で別プロジェクトとして読み込んでください。

右上の「Help」で基本操作と出力方法を確認できます。「更新情報」で変更内容を確認し、ライト／ダークモードも右上から切り替えられます。

## ZIPの確認範囲

2026年10月16日、形式1.1.0の単一スクリーンパネルと、既存部屋へのスクリーンパネル追加について、実機の読込・クリック・再出力ZIPの照合を確認しました。配置パネルだけのZIPを新規ルームへ読み込む経路や、キャラクターなど他のエンティティがある部屋は未検証です。詳細はアプリのHelpを参照してください。

検証用の部屋ZIP、画面写真、利用者の編集データは、このリポジトリや公開サイトには含めません。
